# Upbit 퀀트 자동매매 봇 (v5.1)

> **투자 조언이 아닙니다.** 이 코드를 쓰다 생긴 손실의 책임은 사용자에게 있습니다. 백테스트는 미래 수익을 보장하지 않으며,
> 아래 숫자는 과거 데이터 기준입니다. 잃어도 되는 금액만 사용하세요.

업비트 KRW 현물 코인 17개를 대상으로, 매일 09:00 KST(업비트 일봉 기준)에 목표 비중을 다시 계산해 리밸런싱하는 롱 전용 퀀트 포트폴리오 봇입니다.
24시간 서버(AWS Lightsail)에서 실거래로 운영하는 것을 전제로 만들었습니다.

## 전략
| 단계 | 모델 |
|---|---|
| 추세 점수 | 10·20·40·80·160일 수익률 부호의 평균 (여러 룩백 앙상블 → 특정 기간에 덜 과최적화) |
| 후보 | 점수 > 0, 상장 220일 이상, 30일 평균 거래대금 50억 원 이상 |
| 종목 선택 | 위험조정 모멘텀(수익률 / 변동성)의 **20·30·45·60·90일 종목 간 순위 평균** 상위 5개 (v5.1) |
| 비중 | 점수 / 변동성 (변동성 역가중) |
| 변동성 타기팅 | 60일 공분산으로 계산한 포트폴리오 변동성을 연 30%로 맞춤 (레버리지 없음) |
| 시장 국면 | BTC 종가가 50일선·100일선 위인 비율(0 / 0.5 / 1)을 곱함 → 둘 다 아래면 전량 현금 |
| 낙폭 제어 | 최근 180일 고점 대비 계좌 낙폭이 깊을수록 비중 축소 (-15% → 절반, 최소 25%) |
| 거래 비용 관리 | 비중 변화 5%p 이하면 거래 안 함, 종목당 최대 35% |

모든 신호는 직전 완성 일봉까지만 씁니다(룩어헤드 없음). 로직은 `strategy_v5.py` 하나를 봇과 백테스트가 함께 씁니다.

## 백테스트 (2019-01 ~ 2026-10, 수수료 0.05% + 슬리피지 0.1%)
| 종목 고르는 방식 | 연환산 | 최대낙폭 | Sharpe | OOS 2023~ 연환산 |
|---|---|---|---|---|
| 지금의 17종목 고정 (2026년 시점에 고름 → **생존 편향, 낙관적**) | 47.0% | -19.4% | 1.89 | 40.7% |
| **매달 그 당시 거래대금 상위 17종목** (생존 편향 제거, `research/pit_universe.py`) | **30.4%** | **-21.9%** | **1.40** | **22.3%** |

- 현실적인 기대치는 아래쪽 줄입니다. 업비트 API 가 상장폐지 종목의 시세를 주지 않아, 폐지 종목까지 넣으면 이보다 조금 더 낮을 수 있습니다.
- 연도별(당시 상위 17): 2019 +39% · 2020 +67% · 2021 +61% · 2022 -5% · 2023 +35% · 2024 +46% · 2025 -15% · 2026 +26%(10월까지)
- 수익은 상승장에 몰리고, 횡보·하락장에서는 현금으로 기다리거나 헛신호로 조금씩 잃습니다. 3개월 넘는 손실 구간도 흔합니다.
- 채택 기준: IS(2019~2022)·OOS(2023~) 모두 개선, 비용 2배에서도 유지, 이웃 파라미터에서 붕괴 없음, MDD -25% 이내, Sharpe 하락 없음.
  `research/` 에 시도한 아이디어와 결과가 있습니다(손절·리밸런싱 주기·보조 지표·변동성 예측 등은 탈락).

## 실행
```
pip install -r requirements-dev.txt
python -m pytest -q                                   # 테스트
PYTHONIOENCODING=utf-8 python backtest_v5.py --quick  # 백테스트 요약 (시세는 data/ 에 자동 다운로드)
python bot_v5.py                                      # 기본은 가상 체결(DRY_RUN=1)
```
실거래 순서: `.env.example` → `.env` 복사 후 작성 → DRY 로 2~4주 → `BOT_CAPITAL` 을 소액으로 두고 `DRY_RUN=0`.
API 키는 **출금 권한 없이, 서버 IP 제한**으로 발급하세요. 같은 계좌에 봇을 두 개 띄우지 마세요.
24시간 서버 설치·운영은 [deploy/README.md](deploy/README.md) 참고.

## 구성
| 파일 | 역할 |
|---|---|
| `strategy_v5.py` | 전략 로직(지표·선택·비중). 실거래 설정은 `LIVE` |
| `bot_v5.py` | 실행 봇: 리밸런싱 주문, 상태 저장, 투자유의 종목 자동 제외, 텔레그램, 헬스체크 |
| `backtest_v5.py` | 검증 리포트 (IS/OOS, 비용, 민감도, 워크포워드, 부트스트랩) |
| `upbit_market.py` | 업비트 투자유의·상장폐지 조회, 종목 편입/제외 후보 규칙 |
| `monthly_check.py` | 월간 자동 점검 → 텔레그램 (성과, 중단 기준, 장부 대조, 실전 vs 백테스트, 체결 비용) |
| `backup_state.py` | 봇 장부 매일 백업 (서버 30일 + 주 1회 텔레그램 파일) |
| `add_capital.py` | 운용 자금 증액/감액 (봇 정지 후 서버에서 실행) |
| `deploy/` | 서버 설치·업로드 스크립트, `.env` 점검, 운영 가이드 |
| `research/` | 전략 개선 실험 스크립트와 결과 리포트 |
| `tests/` | 단위 테스트 |
